# Contribuer

1. Créez une branche dédiée.
2. Gardez les changements ciblés et documentés.
3. Vérifiez qu'aucun secret ou fichier `.env` n'est inclus.
4. Ouvrez une Pull Request avec un résumé clair et les étapes de test.

Les corrections de sécurité, améliorations de documentation et simplifications de configuration sont prioritaires.
