# Politique de sécurité

Ne publiez jamais de token Discord, clé API, secret, numéro de téléphone, code de vérification ou contenu de fichier `.env` dans une issue publique.

Pour signaler une vulnérabilité, contactez le mainteneur via son profil GitHub avec une description, les étapes de reproduction et l’impact potentiel.

Les secrets doivent rester dans les variables d’environnement et tout secret exposé doit être révoqué immédiatement.
